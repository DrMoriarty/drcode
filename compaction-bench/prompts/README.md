# prompts/ — снимок промптов компактзора

Файлы в этой папке — дословные копии системного промпта и шаблона выходной
структуры компактизатора из репозитория drcode. Они фиксируют то, что видела
модель во время прогона бенчмарка, поэтому редактировать их нельзя — при
изменении промпта в drcode снимок здесь обновляется осознанно, вместе с
новой записью в таблице ниже (старые версии можно оставить рядом с суффиксом
даты для воспроизводимости старых прогонов).
